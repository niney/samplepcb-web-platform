# shared-packages

## Purpose [coverage: high — 15 sources]

`samplepcb-web-mono-app`(pnpm 9.15 + Turborepo 2.9.18, Node ≥22, TypeScript 6) 의 scope `@sp` 공용 패키지 중 계약 패키지를 제외한 **4종**을 다룬다. 소스 날짜 범위는 2026-06-30(초기 커밋의 `@sp/config`) ~ 2026-11-06(`@sp/ui` 견적서 시트 bc183102a, utils 계약 테스트 1건은 미커밋 — 2026-11-09 작업트리). 2026-07-03 컴파일 때 3종(`config`·`utils`·`shared`)이던 것이 **`@sp/ui` 신설(2026-09-05)** 로 4종이 됐고, `@sp/utils` 는 단일 파일 4함수에서 **도메인 순수 함수 8모듈 + 단위 테스트 186** 으로 자랐다. 2026-09-19 컴파일 이후 변경은 `@sp/shared` 한 곳(대리 접속 상태 `act-as.ts` 신설 + `api-client.ts` 헤더 주입, 커밋 `672efe63a`)뿐이었다. → **2026-10-12 컴파일 뒤로는 `@sp/ui` 가 다시 자랐다**(커밋 5건, 11-04~06 — 전부 개발의뢰): 견적서 1쪽 **`DevelopQuoteSheet`**(11-04, 11-06 피그마 「통합 견적서」 모양)·화면 캡처 PDF **`downloadElementsPdf`**(11-05)·구성도 문서 파서 **`parseDiagramDoc`** + `DevDiagramSection split`(11-05), 그리고 처음으로 `@sp/*` 밖의 **런타임 의존**(`html2canvas-pro`·`jspdf`)과 이미지 자산을 갖게 됐다. `@sp/utils` 는 **소스 무변경**이고 그 안에 사는 계약 테스트만 186 → **227**(13파일, 작업트리 — 커밋분 226)로 늘었다. `config`·`shared` 는 무변경.

## Architecture [coverage: high — 21 sources]

- **빌드 없는 src 직접 노출**: `shared`·`utils`·`ui` 모두 `main`/`types`/`exports` 가 `./src/index.ts`. 소비 측(Vite·tsx)이 TS/SFC 소스를 그대로 컴파일하며, `turbo.json` 의 `typecheck`·`test` 가 `^build` 에 걸려 있지만 이 패키지들엔 `build` 스크립트 자체가 없다(스크립트는 `typecheck`·`lint`, utils 만 `test`=`vitest run`). 2026-11-04 부터 `@sp/ui` 는 이미지 자산(`src/assets/`)도 import 한다 — [env.d.ts](../../samplepcb-web-mono-app/packages/ui/env.d.ts) 의 `*.svg`·`*.png` 모듈 선언은 타입만이고 URL 로 바꾸는 것은 소비 앱의 Vite 다(서버 `api` 는 `@sp/ui` 를 import 하지 않는다).
