- Figma export 는 레이어 **블렌드 모드를 버린다**(불투명도는 알파로 남음). 패턴 레이어를 옮길 땐 `use_figma` 로 `blendMode` 를 먼저 확인할 것.
- 셸에서 `cd X && curl … &` 처럼 백그라운드(`&`)를 붙이면 `cd` 가 서브셸에만 적용돼 다음 명령의 파일이 원래 cwd(리포)에 떨어진다.
