개발 의뢰 세부 질문 최종 정리

새 개발 메뉴 6개 기준 · 고객 질문 및 화면 표시 규칙

운영 기준시스템 개발회로 설계PCB 설계펌웨어역설계앱 및 서버표시 규칙

질문 구성 기준

개발요청서와 첨부 자료를 먼저 분석하여 이미 확인된 내용은 다시 묻지 않습니다. 선택형 질문은 고객이 모르는 경우 상담을 선택할 수 있도록 합니다.

전원은 전원 형태와 입력 전압 또는 범위만 확인합니다. 전원 부품, 배터리 용량, 충전·보호 회로 등 상세 설계는 전문가가 검토하여 제안합니다.

아래 PCB·앱·서버 질문은 앞서 정리한 제안안으로, 기존 운영 문항 유지 여부는 적용 전 확인합니다.

01. 시스템 개발 (통합)

고객 설명과 자료를 분석하여 필요한 항목만 질문합니다. 외관과 기구 준비 여부는 확인합니다.

질문선택지 또는 입력 내용
1. 어떤 제품 또는 시스템을 개발하려고 하시나요?제품 목적과 사용 환경 직접 입력
2. 제품이 어떤 동작을 해야 하나요?입력 → 처리 → 표시·제어 순서
3. 현재 어느 단계까지 준비되어 있나요?아이디어 / 요구사항 정리 / 시제품 보유 / 기존 제품 개선 / 잘 모르겠어요
4. 어디까지 개발이 필요하신가요?회로 / PCB / 펌웨어 / 앱 / 서버 / 기구 / 전문가와 상담
5. 제품은 어떤 환경에서 사용하나요?실내 / 실외 / 산업 현장 / 차량 / 휴대용 / 기타
6. 제품의 입력 전원은 어떻게 준비할까요?어댑터 / SMPS / 충전식 배터리 / 1차 배터리 / 기타 / 잘 모르겠어요·전문가 추천
입력: 전압 ___ V 또는 범위 최소 ___ V ~ 최대 ___ V / 잘 모르겠어요
7. 외부 장비 또는 사용자와 어떻게 연결하나요?유선 / 무선 / 화면·버튼 / 연결 필요 없음 / 잘 모르겠어요
8. 필요한 인증이나 적용 국가가 있나요?KC / CE / FCC / 기타 / 잘 모르겠어요
9. 제품의 외관 디자인은 어떻게 준비하시나요?고객 제공 / 신규 디자인 필요 / 기존 제품 활용 / 상담 필요
10. 제품의 기구·케이스 설계는 어떻게 준비하시나요?고객 제공 / 신규 설계 필요 / 기존 케이스 사용 / 상담 필요
요청서에 ‘DC 24V’가 명시되어 있으면 24V를 추천하고 고객이 확인·수정합니다. 명시되지 않은 범위는 임의로 추정하지 않습니다. 전압의 AC/DC는 요청서에서 확인된 경우 함께 표시합니다.

02. 회로 설계

1. 어떤 회로 설계가 필요하신가요?신규 회로 설계 / 기존 회로 수정·개선 / 단종 부품 대체 / 전문가와 상담
2. 제품의 입력 전원은 어떻게 준비할까요?어댑터 / SMPS / 충전식 배터리 / 1차 배터리 / 기타 / 잘 모르겠어요·전문가 추천
입력 전압 ___ V 또는 최소 ___ V ~ 최대 ___ V / 잘 모르겠어요
3. 반드시 사용해야 하는 부품이 있나요?정해진 부품 있음 / 후보 부품 있음 / 지정 없음 / 전문가 추천
추가 입력: 부품명·모델명
4. 어떤 입력이나 통신 기능이 필요한가요?센서 입력 / 버튼·스위치 / 화면 표시 / 유선 통신 / 무선 통신 / 기타 / 잘 모르겠어요
5. 제품에서 직접 제어할 대상이 있나요?모터·팬 / 릴레이·밸브 / 히터 / LED·조명 / 스피커 / 없음 / 잘 모르겠어요
6. 필요한 인증이나 적용 규격이 있나요?KC / CE / FCC / 전기안전 / 기타 / 잘 모르겠어요
7. 어떤 결과물을 받고 싶으신가요?회로도 원본 / 회로도 PDF / BOM / 전문가 추천

03. PCB 설계

1. 회로도와 부품 정보가 준비되어 있나요?회로도·BOM 보유 / 일부 자료만 보유 / 자료 없음 / 상담 필요
2. PCB 설계 작업 범위는 무엇인가요?신규 설계 / 기존 PCB 수정 / 전문가와 상담
3. 원하는 PCB 크기와 형태가 있나요?크기 지정 / 기구 도면 제공 / 제한 없음 / 상담 필요
4. PCB 층수와 종류가 정해져 있나요?1층 / 2층 / 4층 / 6층 이상 / FPCB·Rigid-Flex / 전문가 추천
5. 특별히 고려해야 할 회로가 있나요?RF·안테나 / HDI / Build-up / 임피던스 제어 / 고속 신호 / 고전압·대전류 / 정밀 아날로그 / 해당 없음 / 잘 모르겠어요
6. 사용해야 하는 PCB 설계 프로그램이 있나요?Altium / OrCAD·Allegro / PADS / KiCad / 기타 / 제한 없음
7. 어떤 결과물을 받고 싶으신가요?PCB 설계 원본 / Gerber·드릴 / BOM / 부품 배치 자료 / 3D 자료 / 전문가 추천

04. 펌웨어 개발

1. 펌웨어를 개발할 하드웨어가 준비되어 있나요?동작하는 보드 보유 / 회로도만 보유 / 보드 개발 중 / 하드웨어 개발도 필요 / 상담 필요
2. 사용하려는 MCU 또는 개발 플랫폼이 있나요?STM32 / Nordic nRF / ESP32 / Linux 기반 보드 / 기타 / 전문가 추천
3. 제품이 어떤 순서로 동작해야 하나요?입력값 → 판단 조건 → 동작 결과 직접 입력
4. 어떤 통신 기능이 필요한가요?UART·RS-232 / RS-485·Modbus / CAN / Ethernet / USB / BLE / Wi-Fi / Zigbee / Thread / LoRa / LTE·LTE-M·NB-IoT / 5G / 기타 / 없음 / 잘 모르겠어요
5. 펌웨어를 어떻게 업데이트하나요?원격 업데이트(OTA·FOTA) / 케이블 연결 / 업데이트 필요 없음 / 전문가 추천
6. 통신 오류나 제품 이상이 발생하면 어떻게 동작해야 하나요?재시도 / 오류 알림 / 안전 상태 전환 / 자동 복구 / 오류 기록 / 전문가 추천
7. 어떤 결과물을 받고 싶으신가요?소스 코드 / 실행 파일 / 다운로드 방법 / 사용자 매뉴얼 / 시험 결과 / 전문가 추천

하드웨어 개발도 필요한 경우 회로 설계·PCB 설계 선택을 안내합니다.

05. 역설계

고객이 제공한 PCB를 기준으로 필요한 작업과 결과물을 선택합니다.

1. 어떤 PCB를 제공하실 예정인가요? 여러 개 선택

PCB 단품 / 케이스에 조립된 완제품 / 동작하는 샘플 / 고장 난 샘플 / 사진·자료로 먼저 상담 / 잘 모르겠어요

추가 입력: 제품명·모델명, PCB 크기, 제공 가능한 수량

2. 어떤 작업이 필요하신가요? 여러 개 선택

회로도 작성PCB의 연결 관계를 분석하여 회로도 작성
BOM 작성실장 부품을 확인하여 부품 목록 작성
PCB Layout 복원부품 배치와 배선을 분석하여 PCB 설계 데이터 작성
Gerber 파일 생성PCB 제작용 Gerber 및 드릴 파일 생성
펌웨어 추출MCU 또는 메모리에 저장된 프로그램의 추출 가능 여부 확인
PCBA 제작 및 검증복원 자료를 기반으로 PCBA 제작 및 협의한 기능 비교
기존 제품 개선기존 PCB를 바탕으로 부품 변경 또는 기능 개선
전문가와 상담필요한 작업 범위를 담당자와 협의

Gerber 파일을 선택한 경우 PCB Layout 자료의 보유 여부를 확인하고, 없으면 복원 범위를 함께 검토합니다.

3. PCB에 대해 알고 있는 정보를 알려주세요. 여러 개 선택

1~2층 / 4층 이상 / 층수 모름 / BGA 등 하부 단자 부품 / 부품 표기 확인 어려움 / FPCB·Rigid-Flex / 잘 모르겠어요

추가 입력: PCB 크기, 대략적인 부품 수, 주요 IC 모델명

4. 샘플을 분해하거나 파괴 분석할 수 있나요?

비파괴 분석만 가능 / 부품 탈착 등 분해 가능 / PCB 절단·층별 분리 등 파괴 분석 가능 / 분석 방법 확인 후 결정 / 잘 모르겠어요

분석 방법과 샘플 반환 가능 여부는 진행 전 협의합니다.

5. 펌웨어 추출 관련 자료가 있나요? 펌웨어 추출 선택 시

MCU·메모리 부품명을 알고 있음 / 원본 파일 또는 소스 보유 / 다운로드 장비·방법을 알고 있음 / 관련 자료 없음 / 잘 모르겠어요

추가 입력: MCU·메모리 모델명, 보유 파일 형식, 읽기 보호 여부

추출 가능 여부는 부품과 보안 설정에 따라 확인이 필요합니다. 읽기 보호가 설정된 경우 추출을 보장할 수 없으며, 보호 기능 우회는 별도 검토 대상입니다. 추출이 불가능하면 신규 펌웨어 개발 상담을 안내합니다.

6. 어떤 PCBA 검증이 필요한가요? PCBA 제작 및 검증 선택 시

기존 PCB와 동작 비교 / 전원·기본 입출력 / 통신 기능 / 전체 기능 / 시험 기준서에 따른 검증 / 전문가와 상담

추가 입력: PCBA 수량, 시험 방법, 연결 장비, 합격 기준. 원본 샘플과 시험 환경에 따라 검증 범위를 협의합니다.

7. 어떤 형태로 결과물을 받고 싶으신가요? 여러 개 선택

회로도 PDF / 회로도 원본 / BOM / PCB Layout 원본 / Gerber·드릴 / 추출 가능한 펌웨어 파일 / 제작된 PCBA / PCBA 시험 결과서 / 전문가와 상담

추가 입력: 원하는 설계 프로그램 및 파일 형식

8. 분석 대상 제품에 대한 권리 또는 분석 허락을 확인해 주세요. 필수

자사 제품이며 관련 권리 보유 / 권리자의 분석 또는 복원 허락을 받음 / 단종 제품 유지보수 목적으로 권리 확인이 어려움 / 권리 확인을 위해 상담

단종품 유지보수 또는 권리 확인이 필요한 경우 담당자가 작업 가능 여부를 확인합니다.

06. 앱 및 서버 개발

개발 범위

1. 어떤 플랫폼에서 사용할 앱인가요?Android / iOS / 태블릿 / 웹앱 / 전문가 추천
2. 앱에서 어떤 기능이 필요한가요?장치 연결·제어 / 상태 확인 / 데이터 표시 / 알림 / 설정 변경 / 기타
3. 앱이 장치와 직접 연결되나요?BLE / Wi-Fi / USB / 직접 연결 없음 / 잘 모르겠어요
4. 로그인과 사용자 관리가 필요한가요?로그인 필요 / 관리자·사용자 구분 / 로그인 불필요 / 상담 필요
5. 화면 디자인이나 기획 자료가 있나요?완성된 디자인 보유 / 기획서만 있음 / 새로 제작 필요 / 상담 필요
6. 앱 배포와 유지보수도 필요한가요?앱스토어 등록 / 내부 배포 / 유지보수 필요 / 개발만 필요 / 상담 필요

서버 개발 서버 선택 시 표시

1. 서버에서 어떤 기능이 필요한가요?장치 데이터 수집 / 데이터 저장 / 관리자 화면 / 사용자 관리 / 알림 / 외부 시스템 연동
2. 어떤 장치 또는 서비스와 연결하나요?IoT 장치 / 모바일 앱 / 웹 서비스 / 외부 API / 기타 / 상담 필요
3. 통신 방식이 정해져 있나요?MQTT / HTTP·REST API / WebSocket / 기타 / 전문가 추천
4. 서버를 어디에 운영할 예정인가요?AWS / Azure / Google Cloud / 고객사 서버 / 미정
5. 데이터 보관과 조회 기능이 필요한가요?실시간 조회 / 이력 저장 / 그래프·통계 / 파일 다운로드 / 상담 필요
6. 운영과 유지보수도 필요한가요?구축만 필요 / 배포까지 필요 / 운영·유지보수 필요 / 상담 필요

화면 표시 및 분기 규칙

  • 시스템 개발은 단독 선택, 나머지 메뉴는 복수 선택할 수 있습니다.
  • 요청서 분석 결과가 있는 질문은 확인 가능한 값만 추천하고 고객이 수정할 수 있습니다. 알 수 없는 값은 추정하지 않습니다.
  • 여러 메뉴에서 공통으로 필요한 질문은 한 번 표시하고 해당 분야의 검토에 활용합니다.
  • 앱·서버 범위에 따라 관련 질문만 표시합니다. 역설계의 펌웨어 추출과 PCBA 검증 상세 질문도 선택 시에만 표시합니다.
  • 펌웨어만 또는 앱·서버만 선택하면 해당하지 않는 PCB 제작·조립 질문은 숨깁니다.
  • 역설계 권리 확인을 제외한 질문은 건너뛰기 또는 상담 선택이 가능하도록 합니다.
  • ‘없음’이나 ‘잘 모르겠어요’는 같은 질문의 다른 선택지와 동시에 선택되지 않도록 합니다.
