# BOM 저장 부품 R/C 우선 검색 실험

## 목적

MPN이 없는 저항·캐패시터는 DB/ES에 이미 저장된 공급사 부품을 먼저
활용한다. 최소 기술조건에 맞는 후보가 있으면 외부 공급사 API 호출을 생략해
검색시간과 호출량을 줄인다.

## 적용 조건

- 저항: 저항값과 패키지가 모두 엔진 검색계획의 hard 조건이고 후보와 일치
- 캐패시터: 정전용량과 패키지가 모두 엔진 검색계획의 hard 조건이고 후보와 일치
- MPN이 없는 단일 검색계획
- ES 문서에 하나 이상의 실제 오퍼가 존재
- sp-engine의 `resistor_minimum` 또는 `capacitor_minimum` 정책으로 다시
  검증했을 때 `automatic_selected`

공차·전압·유전체 등은 이 실험의 선정 필수조건에서 제외한다. 다만 sp-node가
ES 일치만으로 선정하지는 않는다. ES는 후보 조회만 하고 최종 기술·조달 판정은
항상 sp-engine이 담당한다.

## 가격·재고 취급

저장 시점의 가격·재고는 오래됐을 수 있으므로 저장 부품 최소조건 판정에는
사용하지 않는다. 선정 결과는 `catalog_selected`로 저장되어 재고 확인·가격
문의 상태가 된다.

후보 패널의 **외부 공급사 추가 검색**을 누르면 해당 행만 저장 부품 우선 단계를
우회하고 기존 sp-engine 공급사 검색을 실행한다. 완료 결과는 기존 규칙대로
해당 행의 후보와 선정을 갱신하고, 공급사 결과는 기존 백그라운드 저장
파이프라인에 저장된다.

## 관리자 켜기·끄기

**관리자 설정 → BOM 견적 → 공급사 검색 운영 → 저장된 부품 우선 검색**에서
실험 기능을 켜거나 끈 뒤 저장한다. 설정은 `sp_config.bom_quote`의
`storedPartPrioritySearchEnabled`에 저장되며 서버 재시작 없이 다음 검색부터
적용된다. 기존 설정 JSON에는 기본값 `true`가 자동 병합되어 현재 동작을
유지한다.

검색 실행은 시작 당시 값을 실행 옵션에 스냅샷으로 저장한다. 관리자가 실행
도중 값을 바꾸더라도 진행 중인 검색과 엔진 잡 복구는 같은 정책을 유지하고,
새로 시작하는 검색부터 변경값을 사용한다.

비활성화해도 기존 SamplePCB R/C·커넥터 자체 카탈로그 우선 검색, 이미 저장된
선정 결과와 검색 이력, 행별 **외부 공급사 추가 검색**은 그대로 유지된다.
