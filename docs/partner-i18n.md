# 파트너 포털 언어 지원

2026-09-06 구현. `/app/partner/**`에서 한국어·영어·중국어 간체를 지원한다.
사용자 제공 `SAMPLEPCB_파트너포털_한국어표현_개선안.docx`를 기본으로 삼되,
문구 때문에 실제 업무 의미가 달라지는 부분은 아래 예외를 적용했다.

## 언어 선택과 적용 범위

- 헤더에서 `한국어 / English / 简体中文`를 선택한다. 기본은 한국어이며,
  선택은 브라우저 `localStorage`의 `sp.partner.locale`에 저장한다.
- BOM·PCB 대시보드, 견적 요청·회신, 발주 상세·EQ·A/S, 출하 준비·완료 내역,
  입금 현황, 보유 재고·업로드 검토·행 수정에 적용한다.
- 포털에서 여는 공용 회신 폼, 확인창, 인보이스 편집, 포장 명세서,
  거래 서류, QR 라벨 화면·출력 문구도 같은 언어를 따른다.
- 표준 상업송장의 기존 영문·중문 인쇄 헤더, 사용자가 작성한 설명·메모·업체명·주소,
  업로드 파일 원문은 자동 번역하지 않는다. `Stock`이라는 명시적 납기 표현만
  화면에서 재고 보유로 표시하며 다른 납기 문자열은 추정하지 않는다.
- PHP 로그인·회원정보 화면, 발송 이메일, 포털 밖 매직링크 회신 페이지는 별도 범위다.
  이 작업은 계정별 언어 저장이나 서버 문서·메일 언어 정책을 추가하지 않는다.

## 한국어 표현의 적용 기준

| 항목 | 적용 표현과 의미 |
|---|---|
| 모듈·메뉴 | 부품 조달, 대시보드, 견적 요청, 발주 관리, 출하 준비, 출하 완료 내역, 입금 현황, 보유 재고 |
| 발주서 | 메뉴 제목은 발주 관리. 실제 발주 문서는 발주서로 유지 |
| 출하 편성 | 품목 선택이 아닌 발주서 단위. 박스 비유는 출하 목록으로 바꾸되 실물 포장 상자는 구분 |
| 진행 중 출하 | 선적 요청·통관 등도 포함하므로 모두 배송 중이라고 표현하지 않음 |
| 완료 내역 | 운송 최종 상태 또는 입고 확인. 운송 종료만으로 입고 확인 완료를 표시하지 않음 |
| 업무 흐름 | PCB EQ·생산, 국내·국외 운송 단계 유지. 입금은 별도 상태 |
| 입금 합계 | 무상 A/S에 따른 재생산 발주만 제외. 유상 재생산까지 제외하지 않음 |
| 통화 | 통화별 합계와 실제 발주 통화 유지. 언어 변경은 환전이 아님 |
| 검색 | BOM은 견적명, PCB는 프로젝트명·거래 상대·발주 번호. 검색 기능 확장 없음 |
| 재고 정보 | 품번만 있는 행도 허용. 업로드일·갱신 주기 표시가 실재고 검증을 뜻하지 않음 |
| 납기 | 자유 입력은 납기 정보, 실제 날짜 항목은 납기일로 별도 번역 |

## 구현 경계

- `apps/web/src/partner/i18n-core.ts`: 로케일 검증, 변수 치환, 날짜·통화 표시.
- `apps/web/src/partner/i18n.ts`: 포털 범위의 Vue 주입 컨텍스트와 언어 선택 저장.
  `PartnerLayout`만 번역 범위를 제공한다. 전역 `vue-i18n` 인스턴스를 변경하지 않는다.
- `apps/web/src/partner/locales/{common,bom,pcb,shipment,parts}.ts`: 원문 키와
  `[한국어 개선문, 영어, 중국어 간체]` 튜플. 공통 원문은 `common`에 한 번만 둔다.
  같은 원문이라도 의미가 다른 경우 납기일·납기 정보처럼 키를 분리한다.
- `pt(source, params)`는 호출자가 지정한 UI 문구만 번역한다. DOM 텍스트를 검색하거나
  사용자 입력 데이터를 치환하지 않는다. 공용 컴포넌트가 포털 밖에서 사용되면
  원문을 반환하여 관리자·고객 화면의 문구를 보존한다.
- 문장은 완전한 템플릿과 변수로 관리한다. 영문 수량은 `Total: {count}`처럼
  단복수 어형에 의존하지 않는 표현을 사용한다. 코드·상태값·선택지의 제출값은 번역하지 않는다.
- 날짜 표시는 한국 업무일 기준 `Asia/Seoul`을 유지한다. 날짜 입력과 API 저장값은 변경하지 않는다.
- 포털 진입 시 문서 `lang`을 선택 언어로 설정하고 퇴장 시 복원한다.
  텔레포트된 모달도 올바른 언어를 상속한다. 언어 변경 시 임시 오류만 초기화하고 입력 초안은 유지한다.

## 검증

`e2e/specs/partner-i18n.e2e.test.ts`는 번역 누락 언어·변수 불일치·중복 키,
공용 컴포넌트의 원문 유지, 변수 데이터 보존, 통화·날짜 경계를 검사한다.
브라우저 검증은 모든 API와 로그인 응답을 모의 처리하므로 DB 쓰기·메일 발송이 없다.

```powershell
# samplepcb-web-mono-app 에서 실행
pnpm --filter e2e exec vitest run specs/partner-i18n.e2e.test.ts
pnpm --filter e2e exec cross-env PARTNER_I18N_E2E=1 vitest run specs/partner-i18n.e2e.test.ts
pnpm -r typecheck
pnpm --filter web lint
```

브라우저 검증은 실행 중인 Vite `http://localhost:5173`와 설치된 Chrome을 사용한다.
다른 호스트에서는 `PARTNER_I18N_URL`로 재정의할 수 있다.
확인 대상은 언어 전환·재접속 유지, BOM·PCB 목록, 재고 표·행 편집·삭제 확인창,
사용자 원문 유지, 통화별 합계, 390px 모바일 표시, 관리자 한국어 유지다.
견적 회신 폼에서는 검증 오류 후 언어를 전환해도 금액·납기일·메모 초안이 보존되고,
저장 요청의 값도 유지되는지 검사한다.
