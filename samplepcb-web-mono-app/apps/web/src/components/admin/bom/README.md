# 관리자 BOM UI 스냅샷

이 폴더는 2026-07-28 고객 BOM 워크벤치의 관리자 전용 표시 컴포넌트 스냅샷이다.
일반 화면 개편이 관리자 화면에 자동 전파되지 않도록 `components/bom/`과 의도적으로 분리한다.

- API 계약과 조회·저장 훅, 포맷·공급사 메타데이터는 `src/bom/` 원본을 공유한다.
- 범용 이미지 렌더러 `components/ui/PartImage.vue`도 공유한다.
- 양쪽에 적용할 결함 수정은 고객·관리자 컴포넌트에 각각 명시적으로 반영하고 함께 검증한다.
- 단순 중복 제거 목적으로 고객 컴포넌트를 다시 직접 import하지 않는다.
