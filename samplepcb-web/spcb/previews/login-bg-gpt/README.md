- 독립 정적 페이지. 로그인 스킨, 공통 라우트, 인증, DB 연동 없음.
- Figma 원본: [Mask group · 2001:55](https://www.figma.com/design/oviaZUKfcQml2IvwPVICpU/Samplepcb_Web?node-id=2001-55).
- `assets/figma-background.svg`: 2026-09-05 Figma `exportAsync({ format: 'SVG', svgIdAttribute: true })`로 내보낸 원본. 2740 × 1124, 원래 벡터·마스크·그라데이션 유지.
- 바탕색 `#F4F7F8`: 리소스 안내 `2001:59`의 명시값. 이미지는 가로폭에 맞춰 비율을 유지하고 세로 중앙에 배치.
- ON: 아래 7가지 예시 중 하나로 원본 곡선과 빛을 변형. 이 움직임은 미리보기 제안이며 Figma에 명시된 모션 사양이 아님.
- OFF: 프레임 루프를 종료하고 원본 path/transform을 복원한 뒤, 내보낸 SVG 이미지를 그대로 표시. 중간 프레임에서 일시정지하는 방식이 아님.
- `prefers-reduced-motion: reduce`에서는 OFF로 시작. 스위치로 직접 ON 가능. 탭이 숨겨지면 연산을 멈추고 돌아올 때 이어서 재생.
- JavaScript 또는 애니메이션 로딩 실패 시에도 원본 이미지는 표시.

## 효과와 조절

| 효과 | 움직임 | 기본 주기 |
|---|---|---|
| 흐르는 물결 | 봉우리와 골이 흐르는 파형 | 14초 |

- 한 주기 4~40초, 변형 강도 0~100%, 물결 밀도 0.5~3배, 움직임 시차 0~100%, 빛 움직임 0~100% 조절.
- '360° 연속 흐름'은 회전 각도를 한 방향으로 증가시키며, 가로 중앙(x=1370)에서 양쪽으로 꼬임이 전파되도록 공간적인 시차를 준다. 위아래 위치와 앞뒤 깊이를 각각 코사인/사인으로 투영하여 90°와 270°에서 다른 쪽을 지나게 한다. 기본값은 한 바퀴 18초, 강도 100%, 꼬임 밀도 1.2배, 시차 35%, 빛 25%. 한 바퀴를 지나도 같은 회전 상태와 속도로 연결되며, 재생 중 원본 정지 자세로 초기화하지 않는다. OFF에서는 원본 이미지를 표시한다. 끝부분은 움직임이 잦아들도록 처리했다. 기존 링크와 저장 설정을 위해 효과 키는 `right-swap`을 유지한다.
- 새 효과 바로 열기: `https://local-web.samplepcb.co.kr/spcb/previews/login-bg-gpt/#effect=right-swap`.
- 빛 움직임은 별도로 끌 수 있다. 변형 강도 0%는 원본 곡선, 빛도 끄면 모든 장식이 정적이다.
- 일시정지는 현재 모양을 유지한다. 정지 중 슬라이더를 조절하면 같은 시점의 변형을 비교할 수 있다.
- 다른 효과를 고르거나 '효과 기본값'을 누르면 해당 효과의 기본 조절값과 시작 시점으로 돌아간다. OFF/일시정지 상태는 유지한다.
- 패널은 접을 수 있다. 모바일에서는 배경이 화면 위쪽에 고정되고 설정을 스크롤한다.
- 설정은 `localStorage`의 `spcb.background-preview.v2`에 저장한다. 재생 여부는 저장하지 않으며 동작 줄이기 설정을 우선한다.
- '현재 설정 링크 복사'는 URL hash에 효과와 조절값을 담는다. 링크 값은 브라우저 저장값보다 우선하며, 열린 링크에서 설정을 변경하면 주소도 갱신한다. 숫자는 허용 범위로 제한한다.
- 클립보드 권한이 없으면 복사할 링크를 입력칸에 표시한다. 브라우저 저장이 차단되어도 조절과 링크 공유는 가능하다.

## 구현과 확인

`motion-path.js`는 내보낸 원본의 합쳐진 윤곽에 연속적인 좌표 변형을 적용한다. 긴 Bézier 구간도 촘촘하게 샘플링하여 강한 변형에서 모서리가 생기지 않게 한다. 새로운 곡선을 그리지 않으며, 교차 부위를 임의의 개별 조각으로 분리하지 않는다. 원본 SVG 파일은 변경하지 않는다. `preview.js`가 최대 30fps 재생, 설정, 저장과 공유를 담당한다.

2026-09-05 시스템 Chrome에서 6개 효과, 실시간 조절, 일시정지/재개, OFF 원본 픽셀 복원, 강도 0, 효과 초기화, 저장 복원, 공유 링크 왕복/클립보드 실패 대체, 잘못된 설정값 제한, 동작 줄이기, 키보드 및 JavaScript 비활성화를 확인했다. 데스크톱 1440×1000, 작은 화면 800×600, 모바일 390×844에서 배치와 모바일 고정 미리보기를 확인했다.

2026-09-06 '360° 연속 흐름': 좌우 윤곽점의 64개 회전 구간에서 회전 방향이 일정하고 총 회전각이 각각 360°인 것을 확인했다. 반 바퀴·한 바퀴 지점에서도 궤적이 멈추지 않으며, 0°/360°의 렌더 좌표는 일치한다. 실제 브라우저에서 한 주기 이상 재생한 124프레임 동안 원본으로 튀는 현상은 없었다. 최대 꼬임 밀도·시차의 좌표 범위, 일시정지/OFF, 모바일 배치, 동작 줄이기를 확인했다. 기존 6개 효과는 변경 전과 동일한 좌표를 생성한다.

임시 페이지와 리소스는 이 디렉터리 안에 모아 두어, 검토가 끝나면 폴더 단위로 정리할 수 있다.
